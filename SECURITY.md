# Security policy

`statespacecheck` is a numerical library with no network access or credential
handling, but if you find a security problem (for example in how it is built or
published), please report it privately rather than in a public issue:

- use **Report a vulnerability** on the repository's
  [Security tab](https://github.com/edeno/statespacecheck/security), or
- email <eric.denovellis@ucsf.edu>.

You can expect a reply within a week. Fixes are released as a new version on PyPI;
only the latest release is supported.
